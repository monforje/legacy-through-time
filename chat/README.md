# Беседа с Сююмбике: RAG и тестовый чат

MVP чата из `docs/brainstorm/2026-10-29-character-chat.md`. Читатель — Голос из вещего сна, героиня — Сююмбике в первую ночь в Казани, 1533 год.

## Запуск

```bash
cp chat/.env.example chat/.env   # вписать AI_API_KEY (OpenRouter)
task chat:ingest                 # нарезать корпус и посчитать эмбеддинги
task chat:serve                  # http://localhost:8765
```

Справа на странице открывается панель отладки. В ней можно:
- выставить выборы читателя из эпизода 1 (переменные ink) и сразу увидеть, что из них попадёт героине;
- посмотреть найденные сведения с весами, сам промпт, задержку, токены и цену;
- искать по корпусу вручную.

Другие команды:
- `task chat:search -- "вопрос"` — поиск, каким его видит героиня (фильтр 1533 года);
- `task chat:wiki` — перекачать статьи Википедии;
- `task chat:test` — тесты и линтер.

## Как устроено

| Где | Что |
|---|---|
| `content/stories/golden-cage/chat/` | контент героини, его пишет сценарист: `rules.md` (правила роли), `card.yaml` (голос, словарь, имена для поиска), `ep01.lore.md` (общий для всех канон эпизода), `ep01.state.yaml` (переменные ink в слова), `ep01.night.yaml` (место, год, первая реплика, подсказки, пробуждение) |
| `chat/corpus/` | база знаний для RAG: Markdown с front matter (`source_id`, `title`, `layer`, `rights`, `cite`, `url`, `event_year`) |
| `chat/rag/corpus.py` | нарезка по разделам и абзацам примерно по 900 знаков; год события на каждый фрагмент; разрез там, где текст переходит к более позднему году |
| `chat/rag/index.py` | гибридный поиск: косинус по эмбеддингам `baai/bge-m3` + BM25 по русским основам (Snowball), слияние RRF, не больше 3 фрагментов на источник; кэш эмбеддингов в SQLite |
| `chat/rag/heroine.py` | сборка промпта: постоянная часть (правила, карточка, ночь, канон) + состояние + найденные сведения; мягкие проверки ответа |
| `chat/rag/server.py` | FastAPI: `/api/chat` (SSE: `sources`, `delta`, `done`), `/api/search`, `/api/state`, `/api/report` |
| `chat/web/index.html` | тестовая страница чата |
| `chat/data/` | индекс, кэш, логи `chats.jsonl` и `reports.jsonl` (не в git) |

### Слои и год

У каждого фрагмента есть `layer` и `event_year`. Героиня ищет только в `fact` и `setting`, и только среди фрагментов с годом не позже года ночи. Фрагменты без года проходят фильтр, поэтому разделы о будущем без явной даты нужно размечать вручную. Пометка ставится строкой под заголовком:

```markdown
## Семья
<!-- meta: event_year=1549 -->
```

Слои: `canon`, `fact`, `setting`, `fiction`, `legend`, `interp`. Повторная загрузка Википедии не затирает файлы с такими пометками.

Проверить разметку: `uv run python -m rag chunks` (в `chat/`) печатает каждый фрагмент с его слоем и годом.

### Проверки ответа

Проверки ничего не блокируют, а только показывают флаги в отладке:
- `future` — годы позже 1533 или признаки будущего;
- `anachronism` — слова из `lexicon.never`;
- `out_of_role` — героиня вышла из роли;
- `stage_direction` — ремарки в `*звёздочках*`;
- `too_long` — больше 60 слов;
- `crisis` — героиня вышла из роли по правилу «Кризис».

## Дизайн

Страница нарисована дизайн-системой игры (`docs/brainstorm/templates/DESIGN.md`) и её Blender-китом: `/kit/*.png` раздаётся из `heritage/png3d`. 1 CSS px равен 1 единице игрового канваса 360×780. Спрайты рисует маленький порт `KitImage.cs` на canvas: 9-slice по `slices.txt` и целые плитки по краям. Обычный CSS `border-image` оставляет на стыках срезов волосяные швы, поэтому от него отказались.

| Что | Спрайт |
|---|---|
| реплика героини | `plate` + бирка `label` слева (как `PlateSkin.Plain`) |
| реплика Голоса | `chat-veil` (новый: газ дымчатой мяты, розовый пунктирный шов) + бирка `label-rose` справа |
| выход из роли, ошибка | `plate-rose` + `label-rose` |
| подсказки | `chat-chip` (новый: кремовая кожа в золоте) |
| поле ввода, отправка | `chat-field`, `chat-send` (новые) |
| счётчик ночи | `chat-bead`, `chat-bead-out` (новые) на алой нити |
| конец ночи | `card` + `btn` |
| отладка | `page` |
| значки | `round` + маска `restart`, `gear`, маски `exit`, `flag` (новая) |

Новые спрайты описаны в `heritage/blender/chat3d.py`. Рендер: `blender -b --factory-startup --python-exit-code 1 -P blender/render.py -- chat-veil chat-chip chat-field chat-send chat-bead chat-bead-out flag` (из `heritage/`). Новый материал `gauze` добавлен в `studio.py`.

## Модель

`z-ai/glm-5.3-flash` через OpenRouter. Размышление у неё не отключается, поэтому идёт с `effort: low`, а его текст не возвращается. Замер 29.10.2026: около 3,8 тыс. токенов на входе, ответ около 5 с, примерно $0,0005 за реплику.
