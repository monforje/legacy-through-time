# Оболочка приложения: поведение, состояния, движение

Записано: 2026-10-30. Описывает, что делает каждый элемент макетов `docs/brainstorm/templates/shell/`, в каких состояниях бывает и как анимируется. Живые примеры: `states.html` (матрица состояний и токены движения), `index.html` (экраны). Всё, что ниже помечено «в макете», уже работает на HTML; остальное правило для будущей реализации.

## Общие правила

- **Зона нажатия не меньше 44×44.** Если элемент визуально меньше (кнопки наград 40, поиск 36, замок 28), зона нажатия расширена невидимым `::after`.
- **Недоступное действие не молчит.** Неактивная кнопка выглядит приглушённой (45% прозрачности). Если причину надо объяснить, тап по ней показывает тост (пока в макете не сделано, см. «Дальше»).
- **Двойной тап защищён.** Пока кнопка в загрузке, нажатия на неё игнорируются.
- **Каждое долгое ожидание показывает загрузку:** спиннер в кнопке (действие) или скелетон (экран). Ожидание в макете имитируется токеном `--dur-net` (900 мс).
- **Назад:** стрелка в шапке, системная «назад» и Esc закрывают верхний слой (диалог, панель) или возвращают на предыдущий экран.
- **Пониженная анимация** (`prefers-reduced-motion`): все переходы сжимаются до 1 мс, колесо показывает результат сразу. Подсветка и состояния остаются.

## Состояния элемента (общая схема)

| Состояние | Как выглядит |
|---|---|
| По умолчанию | базовый стиль |
| Наведение (только мышь) | кнопка светлее на 10%, строка списка получает фон `surface-2` |
| Нажатие | кнопка и чип уменьшаются до 94–97%, строка получает фон `surface-2` |
| Фокус с клавиатуры | контур 3px акцентного цвета со смещением 2px |
| Недоступно | 45% прозрачности, курсор «нельзя», нажатие не срабатывает |
| Загрузка | подпись скрыта, по центру крутится спиннер, кнопка не нажимается |
| Выбрано | акцентный фон (чип, сегмент) или акцентная подпись (вкладка) |

## Элементы

| Элемент | Тап / действие | Обратная связь и движение | Особые состояния и крайние случаи |
|---|---|---|---|
| **Кнопка основная / нейтральная** | выполняет действие, ссылкой ведёт на экран | нажатие 120 мс, наведение светлее | загрузка со спиннером, недоступна |
| **Кнопка цены** | запускает покупку | спиннер ~900 мс, затем баланс считается вверх, плашка баланса «подпрыгивает», тост «Зачислено: …» | покупка идёт: кнопка не нажимается; нет сети: экран «Магазин недоступен» с «Повторить» |
| **Плашка валюты «+»** | ведёт в магазин | нажатие 120 мс | число перестраивается без прыжков (табличные цифры), 99 999 помещается |
| **Карусель историй** | свайп листает, тап по боковой карточке выводит её в центр, «Открыть» открывает главы | центральная карточка 100%, боковые 88% и полупрозрачные, точки меняются | «случайная история» крутит иконку и листает на другую карточку |
| **Поиск** | ввод фильтрует список, крестик очищает, Esc очищает | крестик появляется, когда есть текст | пусто: «Ничего не найдено»; фокус: акцентный контур |
| **Чипы лент** | один активный в ряду | подсветка 200 мс | прокрутка по горизонтали, активный остаётся видимым |
| **Нижняя панель** | переход между разделами | нажатие 94%, текущая вкладка подсвечена | бейдж «+3» на «Награды»; при открытой панели «Награды» подсвечена она, а не «Истории» |
| **Панель на главной** | открывается тапом по «Награды», закрывается тапом вне панели и Esc | появление снизу 200 мс | строка недоступна, если нет рекламы или распродажи |
| **Диалог (колесо, награды)** | открывается поверх затемнённой главной, закрывается крестиком или Esc | появление: сдвиг на 16 px и лёгкое масштабирование 320 мс, затемнение мягко проявляется | контент прокручивается внутри окна, шапка и затемнение стоят на месте |
| **Колесо** | «Вращать» крутит колесо, останавливается на выбранном по весам призе | разгон и плавная остановка 3,6 с, тост «Выпало: …» | попытки считаются, при 0 кнопка недоступна; при пониженной анимации результат сразу |
| **Награда** | кнопка активна после таймера | таймер идёт, по нулю кнопка пульсирует, замок исчезает; тап: загрузка, «Получено», тост | получена: кнопка недоступна; режим показа `?fast` сжимает таймеры до 5 секунд |
| **Тумблер / степпер** | переключает настройку | ползунок 200 мс с лёгким перелётом, тост «Сохранено» | недоступен: приглушён; с клавиатуры пробел или Enter |
| **Сегменты (энергия/алмазы)** | переключают панель | индикатор скользит 200 мс | один выбранный всегда |
| **Список чатов** | тап открывает переписку | строки появляются по очереди (шаг 40 мс), нажатие подсвечивает фон | загрузка: скелетоны; пусто: «Пока нет чатов» и «К историям» |
| **Переписка** | отправка по стрелке или Enter | своё сообщение появляется сразу, «печатает…» точками, ответ через ~1,3 с, лента прокручивается вниз | пустое поле: стрелка недоступна; лимит: поле и стрелка недоступны, «Продолжить за 20 💎»; длинные сообщения переносятся |
| **Слова по историям / слова истории** | выбор истории, раскрытие слова | стрелка раскрытой строки поворачивается вниз, строки появляются по очереди | пусто: «Слов пока нет»; «Что это?» показывает тост на 4 секунды |
| **Тост** | сам исчезает | появление 200 мс, уход 120 мс, повторный вызов продлевает показ | один тост на экран; не перекрывает кнопку, которая его вызвала |
| **Скелетон** | — | мерцание 1,4 с | показывается, пока грузятся списки и магазин |

## Токены движения

Длительности: `--dur-fast` 120 мс, `--dur` 200 мс, `--dur-slow` 320 мс, `--dur-spin` 3600 мс, `--dur-loop` 800 мс, `--dur-pulse` 1600 мс, `--dur-shimmer` 1400 мс, `--dur-stagger` 40 мс, `--dur-net` 900 мс (только макет), `--dur-instant` 1 мс (пониженная анимация).
Кривые: `--ease-out` (по умолчанию), `--ease-in-out` (пульс, уход), `--ease-spring` (тумблер, баланс), `--ease-wheel` (колесо).
`check.py` следит, чтобы в стилях не было длительностей мимо токенов и был блок `prefers-reduced-motion`.
