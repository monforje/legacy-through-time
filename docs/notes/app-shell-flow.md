# Оболочка приложения: флоу экранов (наработки)

Записано: 2026-10-01. Только композиция и порядок, дизайн (цвета, стиль) не фиксируем.
Фоны на экранах — фото с разными персонажами.

## Порядок экранов

1. **Заставка студии** — фон + большое лого студии.
2. **Загрузка игры** — фон-фото.
3. **Онбординг-слайдер** — несколько шагов, чтобы продолжить, нужно пройти все.
   - «Истории, основанные на реальных событиях»
   - «Настоящие персонажи»
   - «Наслаждайтесь историями»
   - На каждом шаге кнопка переключения; на последнем — «Начать».
4. **Выбор жанров** (регион / фольклор и т.п.) — идея, см. ниже.
5. **Ещё одна загрузка.**
6. **Модалка-приветствие.**
7. **Главная** — пока не определились.

## Выбор жанров

- Сетка карточек 2 колонки, у каждой — картинка, название, маркер выбора справа сверху.
- Пользователь выбирает **максимум 3**; счётчик «0 / 3»; кнопка «Выбрать» неактивна, пока ничего не выбрано.
- Каждая карточка **пульсирует** (анимация).
- Выбор хранится в состоянии пользователя (до 3 штук).
- В нашем случае вместо жанров: регион и фольклор.
- Референс (только композиция): `genre-select-reference.png`.

## Настройки

- Кнопка-гамбургер в правом верхнем углу.
- По нажатию вылезает модалка с настройками — «приколькная», с характером (детали позже).
- Рядом/для сообщений — toast.
