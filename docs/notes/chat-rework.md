# ИИ-чат: что исправить (запись 2026-10-30, UI обновлён по макетам оболочки)

**Статус 2026-10-30: сделано в ветке `chat-rework`.** Клиент (модель, экраны «Чаты» и «Переписка», энергия), сервер и контент (`content/chat/rules.md`, `card.yaml`), брейншторм чата приведён к замыслу. Не сделано: пункт «Об ИИ-чатах» в настройках, товар «энергия» в магазине, экономика энергии, первая реплика и старт без подсказок (агент по RAG), выбор глав по прогрессу на сервере, арт аватаров. Ниже сохранена исходная постановка.

Текущая реализация чата неверна по замыслу и по интерфейсу. Поправить, когда дойдём до него.
Макеты: `docs/brainstorm/templates/shell/chats.html` (список) и `chat.html` (переписка), состояния и движение: `docs/brainstorm/shell-ux.md`, `states.html`.

## Как сделано сейчас (неверно)

- Чат привязан к «Золотой клетке» и к одной героине, Сююмбике.
- Это «ночь», беседа ведётся во сне, читатель в роли Голоса из сна
  (`docs/brainstorm/2026-10-29-character-chat.md`, §2 и §4; `Night/NightScreen.cs`, `Dream.cs`, `DreamServer.cs`).
- Вход только после эпизода, на экране «Ночь».
- Интерфейс в мире «Золотой клетки»: плашки, фоны и орнамент истории, подсказки-чипы, плашка «Вымышленный диалог · 7/10», настроение в шапке.

## Как должно быть (суть)

- Чат есть у **каждой истории**: это беседа с главным героем (ГГ) этой истории, а не со снами.
- Он **не привязан ко сну**. Это обычный чат с ГГ.
- Характер и настроение ГГ зависят от прохождения: чувства, которые он пережил **на момент вопроса** в истории.
  Механика состояния из ink и лор-пакетов по главам остаётся, как уже настроено. На экране настроение **не показывается**, оно только влияет на ответы.
- Читатель говорит от себя, роль Голоса из сна не нужна (проверить, что убираем её из правил и промптов).

## UI (по макетам)

### Поток

Нижняя навигация, вкладка **«Чат»** → экран **«Чаты»** (список героев начатых историй, как в мессенджере) → тап по строке → **переписка** с героем. Назад из переписки ведёт в список. Из экрана глав истории тоже есть вход в чат с её героем.

### Список «Чаты»

- Только герои **начатых** историй (добавленных в библиотеку). Сортировка по времени последнего сообщения.
- Строка: аватар героя (из мира истории, цветная заглушка до арта), имя, последнее сообщение одной строкой с многоточием, название истории акцентным цветом, время, счётчик непрочитанных.
- Состояния: список, загрузка (скелетоны), пусто («Пока нет чатов», кнопка «К историям»).
- Компонент строки общий со словарём (`list-row`).

### Переписка

- Шапка: стрелка назад, аватар, имя, флаг «Пожаловаться на ответ». Нижней панели на экране нет, чтобы было больше места.
- Сообщения: герой слева, читатель справа (акцентный пузырь). Ответ приходит после «печатает…» (три точки). Новое сообщение появляется с лёгким сдвигом, лента прокручивается вниз.
- Ввод: одно поле, **стрелка вправо внутри поля** отправляет. Пока текста нет, стрелка неактивна. Enter тоже отправляет.
- **Убрано из экрана:** подсказки-чипы, строка «Вымышленный диалог по мотивам истории · 7 из 10», настроение героя.
- Состояния: диалог, пусто (первую реплику героя пишет автор, как раньше), длинное сообщение (перенос), лимит.
- **Лимит:** карточка «Герой устал и ушёл отдыхать», кнопка «Продолжить за 20 💎», поле и стрелка недоступны. Остаток сообщений заранее не показывается, пользователь видит лимит, только когда упирается в него.
- Флаг жалобы остаётся на экране (требование Google Play к приложениям с генеративным ИИ).

### Оформление

Чат живёт в оболочке и оформлен нейтральным UI-китом (`kit.css`). Из мира истории берутся только имя, аватар и цвет аватара. «Наследие» остаётся внутри самой истории.

## Решения по UI (ответы владельца 2026-10-30)

1. **Пометка о вымысле.** Раз её убрали с постоянной строки, решение такое (моё, на согласование):
   - в переписке **системная строка сверху ленты**, она уезжает вместе с историей: «Диалог вымышленный: героя играет ИИ по мотивам истории. Факты смотрите в эпизодах.» (в макете `chat.html`);
   - в настройках пункт «Об ИИ-чатах» с тем же текстом и правилами (пока не нарисован);
   - в описании приложения в сторе строка «ИИ-диалоги с героями историй».
2. **Подсказки и первая реплика.** Отдаём агенту, который будет перерабатывать RAG: он решает, как героя начинать разговор без подсказок.
3. **Токены.** Считаем **энергией**, аккуратно, сверху в шапке переписки (компактная плашка `⚡ 7`). Каждое сообщение тратит 1 энергию, число меняется с анимацией. Когда энергия 0, поле и стрелка недоступны, карточка «Энергия закончилась», кнопка «Пополнить энергию» ведёт в магазин. Прежнее «Продолжить за 20 💎» убрано. **Экономику энергии (цена сообщения, восстановление, лимиты) дорабатываем отдельно**, это пока заглушка макета.
4. **Жалоба на конкретное сообщение.** Нет, остаётся один флаг в шапке.
5. **Список без сообщений.** Нет мнения, мой выбор: серым «Начните разговор» вместо превью (пока не нарисовано).
