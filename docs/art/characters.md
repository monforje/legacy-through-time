# Персонажи (Sprites): промты, ряды в полный рост

Игра в стиле «Клуба романтики»: **спрайты** (этот файл) ставятся поверх **фона** ([backgrounds.md](backgrounds.md)) между диалогами. Спрайт = один человек, **PNG с прозрачным фоном (без фона, без бекграунда)**.

## Как генерируем: рядами в полный рост

Как на референсах (`docs/brainstorm/refs`): герой на экране один, **крупный, узкий и высокий, в полный рост**, а нижний край экрана и облачко реплики закрывают его ниже пояса. Поэтому спрайт рисуем **с головы до ступней**, а игра сама ставит его так, чтобы голова была в верхней части экрана, а ноги уходили за нижний край.

Одна генерация = **одна картинка 16:9 в максимальном разрешении (цель 3840×2160)**, внутри **ряд из четырёх узких вертикальных панелей** (по 960×2160, то есть 4:9), **без фона, с прозрачностью**. Узкие высокие панели нужны, чтобы фигура получилась в полный рост и в большом разрешении (≈2000 пикселей по высоте). Всего **13 генераций = 52 спрайтов**. Ряд героя = один человек в четырёх эмоциях, чтобы лицо и одежда совпали.

```
┌────────┬────────┬────────┬────────┐
│        │        │        │        │
│ панель │ панель │ панель │ панель │   вся картинка 16:9
│   1    │   2    │   3    │   4    │   (3840×2160)
│ (4:9)  │ (4:9)  │ (4:9)  │ (4:9)  │   каждая панель — один
│        │        │        │        │   человек с головы до ног
└────────┴────────┴────────┴────────┴
```

- **Прозрачный фон.** PNG с альфа-каналом, без фона, пола и тени. Вшито в каждый промт.
- **Одна хорошая картинка** на ряд: генерируешь, выбираешь лучшую. Вшито в каждый промт.
- **Узкий силуэт.** Прямая стойка, руки вдоль тела или сложены у пояса, локти прижаты, вуаль, косы и рукава падают вниз и не торчат в стороны. Фигура примерно втрое выше, чем шире.
- **В полный рост.** Обе ступни и обувь видны, фигура занимает ~94% высоты панели, сверху и снизу небольшой запас.
- **Все смотрят чуть вправо.** Игра сама отражает спрайт у героини, и они смотрят друг на друга.
- **Стиль:** фотореализм (кадр из исторического фильма), общий с фонами. Живая кожа, волосы, ткань; не рисунок, не аниме, не кукольная кожа.

Если генератор не умеет настоящую прозрачность (большинство отдаёт RGB):
1. Добавь к промту: `on a flat solid light-grey #D0D0D0 background in every panel and gutter, no gradient, no floor, no shadow`.
2. Вырежи фон: `uvx --from 'rembg[cli]' rembg i row.png out.png`.
3. Проверь края на тёмном и светлом фоне. Серый, а не зелёный, потому что одежда героини зелёная.

## Нарезка и сборка

```
uv run --with pillow python -I - <<'EOF'
from PIL import Image
im = Image.open('row.png').convert('RGBA'); W, H = im.size; w = W // 4
names = ['neutral', 'smile', 'sad', 'angry']          # имена панелей слева направо из списка ряда
panels = [im.crop((i * w, 0, (i + 1) * w, H)) for i in range(4)]
boxes = [p.getbbox() for p in panels]
box = (min(b[0] for b in boxes), min(b[1] for b in boxes), max(b[2] for b in boxes), max(b[3] for b in boxes))
for n, p in zip(names, panels):
    p.crop(box).save(f'{n}.png')                     # одна и та же обрезка для всех эмоций героя: голова не прыгает
EOF
```

Все спрайты кладём в `Assets/Resources/Art/Characters/<файл>.png`. Движок ожидает фигуру в полный рост: после того как придут новые спрайты, я подгоню размер и положение под рефы.
